# ✦ Briefly Reports — Multi-Agent AI Research System

## 📌 About

**Briefly** is a web-based multi-agent AI research application designed to automate in-depth web exploration, source verification, report synthesis, and objective quality auditing using a collaborative team of **LangChain AI Agents and Groq LLMs**.

Built to streamline intelligent knowledge gathering, this system focuses on **real-time web search grounding (Tavily), targeted URL content scraping (BeautifulSoup), structured report generation, and automated critical review** for reliable, hallucination-free research.

No clutter — just an intelligent multi-agent system tailored for real-world research workflows.

## ⚙️ Tech Stack

- **Agent Orchestration**: LangChain, LangChain Core, LangChain Community
- **LLM & Inference**: LangChain Groq, Groq Cloud (`openai/gpt-oss-20b`)
- **Web Search & Scraping**: Tavily Search API, BeautifulSoup4, Requests, lxml
- **Frontend & Web UI**: Streamlit, Custom Dark Theme CSS, BaseWeb
- **Utilities & Environment**: Python-dotenv, Rich, Tenacity, Pandas, Tiktoken

## ✨ Features

- 🔍 Autonomous **Search Agent** powered by Tavily for real-time, verified web sources and snippets  
- 📖 Targeted **Reader Agent** to pick the most relevant URL and extract clean, deep page text via BeautifulSoup  
- ✍️ Structured **Writer Chain** synthesizing research into comprehensive reports (Introduction, Key Findings, Conclusion, Sources)  
- 🧐 Rigorous **Critic Chain** providing automated quality scoring ($X/10$), identifying strengths, and highlighting areas to improve  
- 🌐 Clean, modern dark-themed **Streamlit Web UI** with custom CSS styling and full mobile responsiveness  
- ⚡ Live agent progress visualization with real-time status updates across all pipeline stages  
- 📥 Instant **Markdown (.md) export** with one-click report downloading  
- 🚀 Dual execution support: interactive web application (`app.py`) or lightweight terminal CLI (`pipeline.py`)
